# Connections integration icon sources

These assets are used only as compact navigational identifiers beside the
corresponding product names in SiteRadian's Connections selector. Their use
does not imply endorsement, partnership, or ownership. Third-party marks are
kept subordinate to SiteRadian's interface and are not used in SiteRadian's
own identity.

Source review date: 2026-09-14.

| Local asset | Cards | Identity and authoritative source | Treatment |
|---|---|---|---|
| `openai.svg` | Codex in ChatGPT Desktop; Codex CLI | OpenAI product-family mark served by the official [OpenAI Developers site](https://developers.openai.com/favicon.svg) | Official SVG, losslessly optimized; shared because the text identifies the two Codex surfaces. |
| `claude.svg` | Claude Desktop; Claude Code | Claude mark served by the official [Claude site](https://claude.com/favicon.svg) | Official SVG, losslessly optimized; shared because the text identifies each surface. |
| `antigravity.png` | Antigravity CLI | Full-color icon from the official [Google Antigravity press kit](https://antigravity.google/press) | Official transparent PNG, unaltered. |
| `gemini.svg` | Gemini CLI | Gemini sparkle served by the official [Gemini web app](https://gemini.google.com/app) | Official SVG, losslessly optimized. |
| `cursor.svg` | Cursor | App icon served by the official [Cursor site](https://cursor.com/marketing-static/favicon.svg) | Official SVG, losslessly optimized. |
| `continue.svg` | Continue for VS Code | Plugin icon from the official [`continuedev/continue`](https://github.com/continuedev/continue/blob/main/extensions/intellij/src/main/resources/META-INF/pluginIcon.svg) repository | Official SVG, losslessly optimized. |
| `github-copilot.svg` | GitHub Copilot in VS Code | Copilot glyph from Microsoft's official [VS Code Codicons](https://github.com/microsoft/vscode-codicons/blob/main/src/icons/copilot.svg) repository | Official CC BY 4.0 SVG, losslessly optimized. |
| `opencode.svg` | OpenCode | Product icon from the official [`anomalyco/opencode`](https://github.com/anomalyco/opencode/blob/dev/packages/ui/src/assets/favicon/favicon.svg) repository | Official MIT-repository SVG, losslessly optimized. |
| `command-code.svg` | Command Code | Product symbol from the official [`CommandCodeAI/command-code`](https://github.com/CommandCodeAI/command-code/blob/main/.github/commandcode/symbols/symbol.svg) repository | Official SVG, losslessly optimized. |
| `muse-code.svg` | Muse Code | Neutral terminal/client-type glyph drawn for SiteRadian | Neutral fallback. No separate redistributable Muse Code product mark was established; the glyph deliberately avoids using the Meta corporate mark or implying that Muse Code is Muse Spark. |

All runtime assets are local under `assets/integrations/`; the interface has no
remote image dependency. The adjacent text is the accessible name, so the
images use an empty alternative and `aria-hidden="true"` to avoid duplicate
announcements. A package-local `ATTRIBUTIONS.txt` preserves source and license
credit alongside the assets.
